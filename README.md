# Dungeon Crawler

A browser-based, Diablo-style dungeon crawler. Open `index.html` in a browser to play.

- Click to move, click a monster to attack
- **Q** drinks a healing potion
- Kill monsters for XP; each level gives 5 points to spend on Strength, Dexterity or Vitality (**C** opens the stats panel)
- Clear every monster in the randomly generated dungeon to win
